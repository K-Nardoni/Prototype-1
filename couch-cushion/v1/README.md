# Couch Cushion

An AI-powered micro-savings feature concept for a consumer fintech company — built for everyday Americans living paycheck to paycheck who want to save but can't get started.

**[View the live prototype →](https://k-nardoni.github.io/Prototypes/couch-cushion/)**

---

## What is this?

Traditional savings products fail people like Rebecca — a 20-something community college student working two jobs. They require minimum balances, separate accounts, and lump sum contributions. The barrier isn't motivation. It's accessibility and psychology.

Couch Cushion sits inside the a banking app and uses existing transaction intelligence to find safe-to-spend amounts automatically, then gives Rebecca one simple choice: keep it, stuff it into a named savings cushion, or invest it. No new account. No minimum balance. No cognitive overhead.

See the full product thinking in the [Product Requirements Document](PRD.md).

---

## Prototype

The prototype demonstrates the core decision flow:

- **Safe-to-spend header** — Jade surfaces the amount that's genuinely safe to move after scanning bills, recurring charges, and spending patterns
- **Three-option cards** — Keep in checking / Stuff a cushion (4.1% APY) / Invest it (~6.9%)
- **Live projections** — 6-month and 1-year growth shown on each option before confirming
- **Named cushion input** — Rebecca names her goal ("graduation trip", "rainy day fund") to make it personal
- **Green mid-century couch UI** — Modern banking UI

> Note: This is a front-end prototype. No live API or account data is connected.
